Arquivos do Projeto

Os dados utilizados neste projeto correspondem aos **microdados do Exame Nacional do Ensino Médio (ENEM)**, disponibilizados em arquivos no formato `.parquet`, referentes aos anos de **2018 a 2023**.

Para executar o projeto corretamente, faça o download dos arquivos correspondentes ao ano desejado e **extraia os arquivos `.parquet` para esta pasta do projeto**.

> **Observação:** os arquivos de microdados não são armazenados diretamente neste repositório devido ao seu tamanho. Os dados estão disponíveis nos links abaixo.
